# Аудит и стабилизация MIX Assistant v0.11.1-stable

Дата: 28.11.2026 (Asia/Almaty). Базовый коммит: `7882588196309cddb8aa86f215e5a2009b6c0b59`, pilot27. Ветка: `audit/stabilize-pilot27-20261128`.

## Исходное состояние и архитектура

Статическое приложение: `index.html`, `app.js`, `styles.css`; глобальное состояние и inline-обработчики, localStorage `mix-v1`, sessionStorage для представления, IndexedDB для оригиналов документов. Сервер и платные API не нужны. История последних изменений включала перенос отметок FIT и компактный заказ. Номер в шапке/пакете оставался 0.10.8, URL скрипта — pilot27. Существующий набор тестов не покрывал многие сценарии посещений и резервирования.

## Найденные проблемы и исправления

| Проблема | Исправление и проверка |
|---|---|
| «Матрица не определена» при найденной FIT-точке | В реальном Excel 42 FIT-точки и 27 строк матриц/SKU: 15 FIT-точек отсутствуют в Sheet4. Это неполнота исходных данных. Импортируется код матрицы; вместо общего сообщения показана точная причина, ручной выбор оборудования сохранён. Недостающие матрицы не выдуманы. |
| Жёсткие номера строк заголовков Excel | Поиск заголовков и критериев, сохранение первого магазина и строк с нулевым планом. В предоставленном Excel заголовки стандартные и все 42 FIT-строки читаются; смещение воспроизведено на синтетических вариантах. |
| Неустойчивое сопоставление точек | Приоритет ID, нормализация имени/адреса и суффикса ИП, отказ от неоднозначного совпадения. Неизвестный явный ID не подменяется совпадением имени. |
| Историческая выставленность подменяла проверку полки | Чек-лист наличия независим от SKU/баллов прошлого отчёта. «Есть» убирает позицию из непроверенных, «Нет» переносит в заказ при положительном складе либо в список недоступных. Есть отмена и изменение отметки. |
| Перенос отметок мог затрагивать историю | Копирование последних отметок по ID, отдельные снимки каждого завершённого визита, независимые даты и магазины. Старые ключи читаются, нераспознанные отметки доступны для пересмотра. |
| Рекомендации устаревали после смены склада/дублировались | Пересчёт из текущего склада, дедупликация точных строк SKU, исключение нуля и снятых Flash. Сам склад сохраняет отдельные объёмы/SKU. |
| Неподтверждённые объёмы и региональные правила | Применены подтверждения пользователя для Garage, Somersby, Holsten; Pepsi Zero/Mirinda помечены как требующие уточнения объёма, без автоматического удвоения. Вне-региональные требования не перенесены на Жезказган. |
| Английские названия и упаковки склада распознавались неполно | Единый разбор бренда, вкуса, объёма, тары и кратности; все восемь Lipton в реальных отчётах, Holsten/Carlsberg/Garage/Somersby/Гусь, кеги и BIB. Кеги/BIB показаны отдельными единицами, без дублирования колонок. |
| Повторные/устаревшие импорты и ограниченная история | Идентичные Excel/PDF не задваиваются; уменьшение KPI/возврат к старой дате требуют подтверждения. История отчётов сохраняется снимками. Пустые и повреждённые входы отклоняются. |
| Активный визит терялся при обновлении/перестановке маршрута | Визит сохраняется в localStorage по ключу точки, восстанавливается после перезагрузки; индекс пересчитывается при изменении списка. В визите видна одна активная точка. |
| Заметки клиента и маршрута могли расходиться | Общий ключ магазина с чтением прежних ключей. Неоднозначные одноимённые магазины не делят заметки. |
| Перерисовка закрывала панели и сбрасывала ввод | Сохраняются открытые панели, поиск, черновики и прокрутка представления в sessionStorage. |
| JSON не включал оригиналы IndexedDB | Копия v3 включает все коллекции и оригиналы Base64; полная валидация до записи, поддержка прежних копий, откат при ошибке сохранения/транзакции документов. |
| HTML и Base64 требовали усиления проверки | Перед DOMParser удаляются активные теги, ресурсы и обработчики HTML; проверка дат, содержимого, размера и структуры Base64, UTF-8/Windows-1251. |
| CSV разбивался по каждой точке с запятой | Поддержаны кавычки и переносы, повторный импорт без дублей, ошибки формата и ограничение размера, сохранение транзакционно. |
| SheetJS 0.18.5 имел известные уязвимости | Runtime и тесты переведены на официальную 0.20.3. `npm audit`: 0 известных уязвимостей после обновления. |
| Версия публикации и личные записи в начальном шаблоне | Шапка, пакет, CSS/JS URL согласованы на 0.11.1-stable. Имена из исходного шаблона маршрута убраны; сохранённые пользовательские маршруты не очищаются. |

## Реальные документы

Из указанной пользователем общей беседы найдены и получены доступные оригиналы: Excel KPI, два складских PDF за 26/27.11.2026, два HTML Monolit за эти даты, CSV клиентов и исходный каскадный FIT PDF. Файлы, идентификаторы, названия клиентов и финансовые показатели не включены в репозиторий.

- Excel: прочитаны все пять листов; 27 магазинов с матрицей/SKU, 42 FIT-точки. Независимо через openpyxl проверены планы/факты четырёх категорий, перевод дал ×10 в литры. Структура каталога и критерии FIT проверены отдельно.
- Каждый складской PDF: 91 товарная строка, в том числе восемь Lipton, 14 кеговых и три BIB. Количества каждой строки сверены с независимо извлечённым текстом PDF. Проверены упаковки, россыпь, пустой нулевой остаток, повторный импорт.
- Monolit: 37 и 34 товарные строки; независимый расчёт по HTML-таблицам, количеству, цене и литражу подтвердил суммы, категории и Sell-in, включая бесплатные позиции. Подтверждения гипотезы о фактических сроках зачёта KPI эти документы не дают.
- CSV: в браузере импортированы 43 клиента. Они не заменяются при загрузке ежедневных отчётов.
- FIT PDF: сверены страницы 17–18, 30–31 (национальная группа, Focus, CSD/Lipton/Flash, 1Д/2Д/Flex). Региональные вкусы применены по прямым подтверждениям пользователя. Исторические продажи не использованы как доказательство текущей полки.

## Фактически выполненные браузерные сценарии (Chromium)

1. Импорт реальных Excel, двух PDF, CSV и двух Monolit; повторная загрузка PDF/Excel без дублей. Новая версия SheetJS загрузилась и прочитала реальный Excel.
2. FIT: оборудование Pepsi/пиво 2Д и отдельный Flash, «Нет»/отмена/«Есть» для Pepsi; Holsten Premium сопоставлен Pilsener; компактный заказ; настройки и заметка сохраняются после обновления. Варианты 1Д/Flex/без ХО дополнительно покрыты автоматическими тестами, не все сочетания физически прокликаны.
3. Старт визита, одна активная точка, обновление страницы с восстановлением, завершение статусом «Посещено», повторный визит с последними отметками. После переключения разделов состояние сохраняется.
4. Акции 4+1, 6+1 и без акции, прогноз обеих накладных, фильтры склада и история.
5. В «Документы» сохранён реальный PDF. JSON экспортирован; байты PDF в нём совпали с оригиналом. Затем очищены только тестовые localStorage/sessionStorage и две тестовые записи архива. После импорта копии восстановились активный визит, заметка, оборудование, заказ, отчёты, 43 клиента и оба документа. Повреждённый JSON отклонён без потери существующего отчёта.
6. Все 11 разделов открыты при ширинах iframe 375/390/430 CSS px: во всех 33 случаях `scrollWidth === clientWidth`; визуально проверен узкий FIT-список и нижняя навигация. Chromium отводит 15 px под вертикальную полосу прокрутки на длинных страницах. Переключение разделов возвращало сохранённое место списка.
7. В собранных журналах не обнаружены ошибки приложения; шум расширения браузерного стенда исключён. Это не доказательство отсутствия любых ошибок во всех возможных сценариях.

## Оставшиеся ограничения и непроверенное

- Физический iPhone/Safari, системный буфер/меню «Поделиться» и запуск реальной iOS Shortcut не проверены. Base64 проверен автоматически; все способы передачи файлов iOS нельзя считать проверенными браузером Chromium.
- OCR сканов не реализован. Проверялись предоставленные текстовые отчёты; произвольная структура PDF/Excel/HTML может потребовать адаптации. Повреждённые файлы покрыты автотестами; браузерный тест повреждённого PDF не был доведён до окончательной фиксации результата.
- Не все существующие кнопки во всех состояниях прокликаны отдельно. Раздел зарплаты только открыт для контроля регрессий; новый прогноз зарплаты не разрабатывался. Длительный тест на многомесячной базе и измерение памяти Safari не проводились.
- Матрицы для 15 FIT-точек отсутствуют в оригинальном Sheet4. Приложение не может достоверно восстановить эти значения из названия точки. Требуется полный исходный отчёт либо ручная настройка оборудования.
- Одновременная обязательность разных объёмов Pepsi Zero/Mirinda и фактические сроки попадания отгрузки в KPI остаются неподтверждёнными. Прогноз условный, автоматического определения ходовых товаров нет.
- Хранилище локальное, синхронизации устройств нет. Browser storage имеет конечную квоту; при её исчерпании запись отклоняется с сообщением. История не обрезается автоматически. JSON ограничен 100 МБ, оригиналы внутри копии — 75 МБ. Периодический экспорт нужен для защиты от очистки данных браузера.
- Импорт Excel/PDF зависит от доступности внешних CDN. Полный офлайн-режим не заявлен.
