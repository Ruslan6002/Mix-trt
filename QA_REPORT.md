# Проверка v0.10.8

Дата: 27.11.2026. Исходная версия: `4b40200`, v0.10.6. Её публикация GitHub Pages завершилась успешно. Во время проверки появился коммит `aa39413` с независимым выбором ХО и пивных дверей (v0.10.7); его изменения включены в v0.10.8.

## Исправления

- FIT NonAlco: устранён сдвиг столбцов CSD, Lipton, Focus, Taste и Flash; новые импорты сохраняют заголовки критериев, старые данные поддерживаются.
- Рекомендации доступны в списке FIT по всем магазинам и в ежедневном маршруте. Shop ID используется для связи с отчётом; неоднозначные названия не сопоставляются автоматически.
- Учитываются два дополнительных вкуса Flash и два SKU для точки без ХО. Близкие объёмы одного вкуса не считаются двумя вкусами. Вместо регулярных выражений отображаются названия товаров.
- Показываются подходящие складские позиции, положительный и нулевой остаток; отсутствие позиции обозначается как неизвестный остаток. Снятые Flash исключены.
- Сохранены независимый выбор ХО Pepsi/Lipton, отдельного Flash ХО и пивных дверей 1Д/2Д из `aa39413`. Тип ХО сохраняется по Shop ID с поддержкой ранее сохранённых настроек. Панель рекомендаций остаётся открытой после выбора.
- Цель Flash на главной согласована с прогнозом: 100%. План визитов из итогового KPI отображается отдельно от календарного плана всего месяца.
- Monolit учитывает Sell-in с нулевой ценой, в том числе когда округлённый отчётный объём равен нулю. Добавлена проверка года и совпадения месяца прогноза с KPI.
- Усилена проверка JSON перед восстановлением; старые копии получают недостающие базовые поля. Предыдущее состояние сохраняется перед заменой. Повреждённая исходная запись при запуске не перезаписывается.
- Постоянные заметки сохраняют прежние ключи для чтения; новые ключи не зависят от появления одноимённых клиентов. Очистка заметки не возвращает старый текст.
- Увеличены области нажатия, связаны подписи полей, HTML добавлен в архив документов. JS и CSS вынесены из HTML без удаления функций.

## Ограничения

- Проверялся Chromium. Реальное устройство iPhone/Safari, системное меню «Поделиться» и передача PDF через буфер iOS не проверены. Узкая ширина не заменяет проверку мобильного браузера.
- Складской PDF проверен на контрольном документе с текстовым слоем. OCR сканов и произвольные форматы PDF не реализованы. PDF с обучением FIT не является складским отчётом.
- FIT показывает рекомендации, а не гарантированный прирост: детализация не содержит тип ХО, текущую полку и результаты распознавания фото. Focus требует региональной матрицы и числа дверей.
- JSON не содержит оригиналы документов IndexedDB. Между устройствами автоматической синхронизации нет; очистка данных браузера удаляет локальные записи.
- Первый импорт Excel/PDF зависит от доступности jsDelivr. Функции буфера и «Поделиться» зависят от разрешений и возможностей браузера.
- Полный набор реальных файлов авторасчёта ЦОТ, CSV клиентской базы и складского PDF не предоставлен; их разнообразные форматы нельзя считать полностью проверенными.
