# MIX Assistant · v0.11.1-stable

Личный помощник торгового представителя: KPI, Monolit, маршруты, заметки, FIT Urban, склад, акции и поручения. Статическое бесплатное приложение на GitHub Pages; работа не зависит от включённого компьютера владельца.

Данные остаются в `localStorage` (`mix-v1`), оригиналы документов — в IndexedDB (`mix-documents`). Обновление сайта не меняет эти ключи. Клиентская база и недельные маршруты независимы от ежедневных отчётов. Новая установка начинает с пустой клиентской базы; сохранённые маршруты прежних установок сохраняются.

JSON-копия версии 3 включает все пользовательские коллекции, историю, настройки и оригиналы документов. Старые копии поддерживаются. Перед восстановлением проверяется структура и сохраняется прежнее состояние; исходные документы восстанавливаются без дублирования. Копии содержат конфиденциальную информацию: храните их отдельно от публичного репозитория.

Импорт: пятилистовый Excel KPI MIX (`Sheet1`–`Sheet5`), HTML Monolit, текстовый складской PDF/TXT, CSV клиентов (`название;адрес;ИП`), вставка и Base64. «Документы» архивирует оригиналы; расчёты запускаются в соответствующих разделах. Повторная загрузка идентичного отчёта не добавляет продажи или историю второй раз.

FIT рассчитан на URBAN, Жезказган. Историческая выставленность из Excel не означает текущее наличие: отметьте «Есть»/«Нет» во время визита. Рекомендации к заказу используют положительные складские остатки. Оборудование задаётся вручную. Если точка есть в FIT, но отсутствует в Sheet4, приложение объясняет отсутствие матрицы. Неоднозначные совпадения требуют ручной связи. Обязательность нескольких объёмов Pepsi Zero/Mirinda не предполагается; лаги прогноза Monolit +1/+2 дня обозначены как допущение.

Первый импорт требует интернета для загрузки SheetJS CE 0.20.3 с официального CDN и PDF.js 4.10.38 с jsDelivr. OCR сканов, автоматическая синхронизация между устройствами и определение ходовых товаров не предусмотрены. Работа Safari и системных быстрых команд требует отдельной проверки на iPhone.

Проверки разработчика (Node.js 22+):

```sh
npm ci
npm run check
npm test
npm audit
```

Публичные тесты используют только вымышленные записи. Реальные отчёты и резервные копии не добавляйте в Git. Подробности аудита и границы проверки: [QA_REPORT.md](QA_REPORT.md).
