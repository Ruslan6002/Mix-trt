# Mix-trt
# MIX Assistant · v0.10.8

Личный помощник торгового представителя. Статическое приложение для GitHub Pages: KPI, Monolit, маршруты, заметки, FIT Urban, остатки, акции, поручения и расчёт начислений.

Данные приложения остаются в `localStorage` (`mix-v1`), исходные документы — в IndexedDB (`mix-documents`). При обновлении сайта ключи хранилищ сохраняются. Импортированные отчёты не отправляются в репозиторий.

JSON-копия содержит данные и расчёты, но не исходные документы. Перед восстановлением приложение проверяет структуру копии и сохраняет предыдущее состояние в `mix-before-restore`. Кнопка «Вернуть состояние до восстановления» позволяет его восстановить.

Для анализа Excel нужен пятилистовый отчёт KPI MIX (`Sheet1`–`Sheet5`), для Monolit — HTML ежедневного отчёта, для склада — текстовый PDF или TXT в поддерживаемом формате. Загрузка файла в «Документы» архивирует оригинал; расчёты запускаются в соответствующем разделе.

Для Excel и PDF браузер загружает закреплённые версии библиотек с jsDelivr. Первичный импорт требует интернета. Тип ХО выбирается вручную: его нет в детализации. Рекомендации используют историю продаж; наличие на полке, фейсы, фото, региональную Focus-матрицу и число дверей необходимо подтвердить в магазине.

Проверки разработчика (Node.js 22 или новее):

```sh
npm ci
npm test
npm run check
```

Тесты используют только вымышленные данные. Конфиденциальные отчёты, резервные копии и реальные клиентские базы нельзя добавлять в Git.
